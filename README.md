\# Proyecto R: Análisis y Reporte Reproducible



Este es mi primer proyecto estructurado con las mejores prácticas de ciencia de datos.



\## Herramientas utilizadas

\* \*\*R\*\* y \*\*renv\*\* para el entorno aislado.

\* \*\*Quarto\*\* para generar el reporte final.

\* \*\*Make\*\* para automatizar el flujo de trabajo.

\* \*\*Git\*\* para el control de versiones.



\## Cómo reproducir este proyecto

1\. Clonar el repositorio.

2\. Abrir `1project.Rproj` en RStudio.

3\. Ejecutar `renv::restore()` para instalar las dependencias exactas.

4\. Ejecutar `make todo` en la terminal para generar el HTML.
